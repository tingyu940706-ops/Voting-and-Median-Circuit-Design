# Voting and Median Circuit Design

## Project Overview
This project implements two voting circuit architectures and a 5-input median circuit using Verilog HDL for Practical Digital System Design.

## Implemented Architectures
- Voting Circuit M1 (Bit-wise Counting)
- Voting Circuit M2 (Candidate Matching)
- 5-input Median Circuit

## Features
- Comparator Tree
- Adder Tree
- Partial Sorting
- Critical Path Analysis
- Quartus Timing Analysis
- Exhaustive Testbench Verification

## Tools
- Verilog HDL
- Quartus Prime 20.1
- ModelSim / ncverilog

## Verification
The testbench combines corner cases with exhaustive test to verify functionality and tie-breaking correctness.
